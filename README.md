# Cruzadinha de Arquitetura Computacional

Jogo interativo de palavras cruzadas desenvolvido em HTML, CSS e JavaScript puros para treinar os principais conceitos de Arquitetura Computacional, com visual inspirado na paleta neon de GTA VI e tabuleiro compacto para jogar sem rolagem excessiva.

## Link do jogo publicado

Acesse o jogo pelo GitHub Pages:  
`https://SEU-USUARIO.github.io/arqcomp-cruzadinha/`

*(Substitua `SEU-USUARIO` pelo seu nome de usuário no GitHub após publicar.)*

## Como jogar

1. Leia as pistas divididas entre **Horizontais** e **Verticais**.
2. Clique em qualquer pista ou diretamente nas casas do tabuleiro para começar a digitar (clicar novamente em um cruzamento alterna entre horizontal e vertical).
3. Digite as respostas sem acentos e sem espaços (as letras são convertidas automaticamente para maiúsculas).
4. Clique em **Conferir** para ver quais palavras estão corretas (verde), quais estão incorretas (vermelho) e atualizar o contador de acertos.
5. Clique em **Reiniciar** para limpar o tabuleiro e jogar novamente.

## Palavras e pistas utilizadas

### Horizontais

- **4. UC:** Parte do processador que lê a instrução, interpreta e envia ordens aos demais componentes.
- **5. MEMORIADEMASSA:** Camada permanente da hierarquia, não volátil, que guarda os arquivos e programas instalados.
- **7. ULA:** Circuito do processador que realiza todas as contas matemáticas e operações lógicas.
- **10. MICROCONTROLADOR:** Chip único que reúne processador, memória e periféricos, usado no núcleo do Arduino Uno.
- **11. FLASH:** Memória não volátil e regravável onde fica guardado o programa principal do seu Arduino.
- **12. EEPROM:** Pequena memória não volátil do Arduino para guardar dados que sobrevivem ao desligamento.
- **13. REGISTRADORES:** Memórias minúsculas e ultrarrápidas dentro do processador que guardam dados usados no exato momento.

### Verticais

- **1. CPU:** O grande bloco do computador que busca e executa as instruções do programa.
- **2. DUALCORE:** Chip que possui exatamente duas unidades de execução completas trabalhando ao mesmo tempo.
- **3. RAM:** Memória de trabalho volátil que guarda os programas em execução e seus dados temporários.
- **6. DATABUS:** Grupo de fios do sistema que transporta o valor lido ou as instruções.
- **8. ROM:** Memória não volátil de fábrica que guarda o firmware de inicialização do sistema.
- **9. CACHE:** Memória muito rápida no processador que guarda uma cópia do que foi usado recentemente.
